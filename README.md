# @holesail/holesail-key

Secure key management for Holesail P2P tunneling with AES-256-CBC encryption.

## Installation
`npm i @holesail/holesail-key`

## Features

- 🔐 AES-256-CBC encryption for stored keys
- 🔑 Automatic master key generation
- 💾 Persistent storage in user directory
- 🛡️ Secure file permissions (0o600)
